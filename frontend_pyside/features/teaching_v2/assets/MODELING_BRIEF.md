# 教学台器材建模说明（交给建模手）

共 **20 个 `.glb`**。单位 **1 格 = 1 mm**。导出 **glTF 2.0 `.glb`**。  
参考 Thorlabs 学生实验外形即可，不必 1:1 抄 STEP。**包围盒必须按本表，差 ≤ 0.25 mm。**

`optics_glb_output_v2new` 尺寸/原点已合格。台上现在像色块/圆柱，是外壳细节不够，不是尺寸错。  
**本轮换皮：只改外形和材质，禁止改 AABB、原点、轴向。** 文件名、路径、单位都不许改。

---

## 1. 硬约定（做错会装歪）

### 坐标

右手系：

- **+X** = 光轴（光束前进）
- **+Y** = 横向
- **+Z** = 上

```
侧视（+Y 朝里）                    俯视（+Z 朝外）

      +Z 上                             +Y
       ^                                 ^
       |     光沿 +X                     |
       |    ------>                      |------> +X
  -----+------  原点 = 软件摆放点
```

文件里 **一个 mesh**（可多材质），根节点必须是单位变换（无旋转、无平移、无缩放）。  
验收读的是 **顶点 accessor 的 min/max**，不是 Blender Dimensions，也不是带节点旋转后的外观。

### 原点（Pose）

| 类型 | 用于 | 壳体在哪 |
| --- | --- | --- |
| 出光 / 镀膜 / 刻线面 | 激光、镜、分束、取样、光栅 | 原点在面上，体在 **−X** |
| 入光 / 靶面 | 光纤、CCD、功率计、波前传感器 | 原点在面上，体在 **+X** |
| 光心 / 中心 | 透镜、柱面、波片、隔离器、扩束、光阑、PBS | 原点在几何中心 |
| 上表面 | 面包板、支柱、光纤座 | 原点在顶面，体在 **−Z** |
| 底面 | 示波器 | 原点在底面，体在 **+Z** |

镜子 / 分束 / 取样 / 光栅：**保持竖直平板，禁止预转 45°。** 软件会转。

### 软件会做、网格不要做

- 支柱由程序从壳体下沿接到台面。光学件 **不要挖穿心孔**，不要把杆做进器件。
- 透镜 / 柱面 / 光阑会按用户填的外径、厚度 **非等比缩放**。不要做镜架、SM05 套筒（超出盒子会被压扁）。
- 光束、焦斑、CCD 感光区由程序画。CCD 外壳是 30×30，不要把 4.968×3.726 做成壳体。
- 示波器不立支柱。光纤座不单独添加，和 `fiber.glb` **共用同一个原点**。
- 镜架、支柱座、激光夹、探测器托板、面包板 M6 孔由软件画。不要做进光学件网格，也不要做房间、桌腿、名牌。

### 导出（Blender）

- 单位 mm，Apply All Transforms。
- 导出 glTF：**不要**勾选 +Y Up 来摆正。顶点导出后仍须 +Z 上、+X 沿光轴。
- 不要相机、灯光、空物体、动画、蒙皮、morph。
- 薄片双面或给厚度。玻璃不要 Blend 透明、不要体积焦散。
- 滚花、螺纹、孔阵、光栅槽：**贴图/法线**，不要堆几何。

### 性能（这样不会卡）

单件 **1k–8k** 三角，面包板 **≤15k**。一张 2k 贴图没问题。

不要：布尔 200 个真孔、单件 5 万三角、每件一张 4k、大面积半透明。

### 不要做

桌腿、隔振平台、电源线、跳线、EDFA、HeNe 腔、DOE、品牌 LOGO、超出 AABB 的镜架、Newport 561（高度 79.4）。

## 3. 本轮：外壳换皮（像实物，盒子不动）

不要重做坐标系。打开现有 glb，在 **同一 AABB 里**加倒角、滚花贴图、通光窗、镀膜，再按第 5 节导出覆盖原文件。

软件已经画：支柱（拉长 `post_stem`）、光束、面包板孔。  
支架是 **独立 glb**（`mount_post_base` / `mount_ring` / `mount_clamp` / `mount_km` / `mount_plate`），禁止做进光学件外壳——透镜会按外径非等比缩放，支架跟着压扁。

### 3.1 不要动（软件在画，或台上不用）

| 文件 | 原因 |
| --- | --- |
| `breadboard.glb` | 台上用程序哑光板+孔，不加载此文件 |
| `post_stem.glb` | 程序把 Z 拉到离台高度；只许光杆 |
| `fiber_stage.glb` | 40 mm 塔，台上不画。若要做，另开小座任务，不要改这个盒子去硬塞 |

### 3.2 第一批（默认光路，必须先交）

台上默认就能看见：激光 → 两片透镜 → 光纤。这四件决定「像不像实验」。

| 文件 | 要长什么样 | 禁止 |
| --- | --- | --- |
| `laser.glb` | Thorlabs CPS 量级：黑/金属套管 + **红色端帽或红色环** + 出光窗 Ø4 + 一圈滚花。壳体仍是 Ø11×40 | 整根纯红蜡笔；自发光；按束腰建模 |
| `lens.glb` | 双凸玻璃，边缘 0.3 mm 平边，中心到 x=±1；略透明/高光，能看出是镜片 | 镜圈、SM05、镜架；改成平面圆片 |
| `cylindrical_lens.glb` | 平凸；母线 **+Y**；xz 弓形；沿 Y **12～16 段**（现在侧面太楞） | 改成圆透镜；沿 Y 做波浪 |
| `fiber.glb` | FC 准直头：x=0 插芯 + 滚花螺帽 + 短套管。仍 Ø11×18（软件会缩着画） | 跳线、大尾巴、40 mm 塔 |

### 3.3 第二批（器材库常用）

| 文件 | 要长什么样 |
| --- | --- |
| `mirror.glb` | 竖直圆片，+X 镀膜（银/金高光），背面黑阳极。禁止预转 45° |
| `splitter.glb` / `beam_sampler.glb` | 同镜，更薄；镀膜面在 x=0 |
| `isolator.glb` | 阶梯套管，两端 **Ø3.6 通光窗**，+X 箭头刻线或贴图 |
| `waveplate.glb` | 金属环嵌玻璃，不要刻 HWP/QWP |
| `ccd.glb` | 方盒 + 前窗内凹约 8×6 + C 口环；不要把靶面做成外壳 |
| `aperture.glb` | 打穿的黑圆环，中心能透视 |

### 3.4 第三批（有空再做）

`beam_expander`、`pbs`、`grating`、`power_meter`、`wavefront_sensor`、`oscilloscope`。PBS 立方不转，内部留绕 +Y 的 45° 薄分界面。示波器屏朝 **−Y**，不要真 UI。

### 3.6 支架换皮（台上假，就是这 5 件）

光学件不要带镜架。覆盖这 5 个文件。盒子不许改。参考 PH2/M、LMR05、KM05、V 形激光夹。

| 文件 | 用途 | 原点 | AABB | 外形 |
| --- | --- | --- | --- | --- |
| `mount_post_base.glb` | 台面支柱座 | 底面，体 +Z | X/Y ±12.5，Z 0..10 | 25×25 底板 + Ø18 套筒（内孔 Ø12.9）+ 侧向止动螺钉。支柱从中穿过 |
| `mount_ring.glb` | 透镜/柱面/波片/光阑/隔离器/扩束 | 光心 | X ±5，YZ Ø20 | **LMR 通孔环**，沿 +X 打穿 Ø13.1，能看见镜片。底部可留贴支柱的小平台。不要实心方块 |
| `mount_clamp.glb` | 激光 | 与激光同一出光面 | X −28..−12，Y ±9，Z −13..−5.5 | 管下 V 形夹，不要挡 Ø4 出光窗 |
| `mount_km.glb` | 镜/分束/取样/光栅/PBS | 硬件，体在镀膜面 −X | X −14..−6，YZ ±13 | 方背板 + 两颗调节柱。禁止预转 45° |
| `mount_plate.glb` | CCD/功率计/WFS | 入光面 | X 0..22，Y ±17，Z −21..−15 | 探测器托板，在壳体下方 |

黑阳极，螺钉银。1k–6k 三角。滚花用贴图。

### 3.5 换皮时怎么对齐现有文件

1. 用现有 `frontend_pyside/features/teaching_v2/assets/<name>.glb` 当底板。  
2. 在 Blender 里确认顶点 AABB 已等于本表；**先锁定盒子再加细节**。细节必须待在盒子里（倒角、窗、滚花贴图都可以，凸出的旋钮、镜架不行）。  
3. 覆盖同名文件，不要改名、不要加 `_v3`、不要放进子文件夹。

## 5. 交货

1. 覆盖 `frontend_pyside/features/teaching_v2/assets/` 里同名小写 `.glb`（不要改名）。  
2. 每个文件自报：三角数、accessor AABB（min/max）、原点类型。  
3. 根节点单位变换。  
4. 自检：
   - AABB 与第 2 节差 ≤ 0.25 mm  
   - 光阑能透视中心  
   - 透镜中心比边缘厚；柱面侧面圆滑，母线沿 Y  
   - 镜 / 分束 / 取样 / 光栅仍竖直，不是菱形  
   - PBS 立方没转，内部有斜面  
   - 隔离器两端是小圆窗，不是整面 Ø25  
   - 激光能看出套管+出光窗，不是一根蜡笔  
5. 我方用 `shipped_mesh_violations()` 验收盒子；外形用教学三维目视。
