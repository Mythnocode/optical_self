`default-result-comparison.json` records actual outputs from two jobs in the isolated `%TEMP%/optical-js-training-20260930` backend repository. Original screenshots and geometry/font/column records are produced by `scripts/capture-simulation-baseline.py`; current browser captures are in `tests/golden/ui-current/`.
