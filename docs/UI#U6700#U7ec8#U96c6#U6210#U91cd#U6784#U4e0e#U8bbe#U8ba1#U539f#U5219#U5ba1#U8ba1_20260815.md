# UI最终集成重构与设计原则审计（2026-08-15）

## 1. 本轮目标

本轮以前端“少显示、强上下文、连续研究”为目标，对首页、仿真、参数研究/优化、容差、实验验证、模型分析、SHAP、任务中心、教学中心和AI助手进行统一审查。物理求解公式和冻结物理链不在本轮改动范围内。

八条执行原则：

1. 画布和结果优先，而不是参数优先。
2. 不同任务采用不同页面骨架。
3. 默认简洁、详细设置按需展开。
4. 同一件事归到一起：状态不是页面、明细不是一级页签、容差是方案级后续分析。
5. 即时交互与正式计算分离。
6. 状态自动同步、证据自然呈现、决策由用户完成。
7. AI知道得多，页面显示得少。
8. 颜色、字号和图表考虑录屏与投屏可读性。

## 2. 页面审计与最终状态

### 首页
- 已使用用户指定的新研究闭环主图，文件哈希与原上传图一致。
- 主图下方重复“继续仿真”入口已移除；继续当前工作集中在右侧“当前工作”。
- 无任务时不再常驻“暂无任务”卡；有任务时只显示最近三条摘要。
- 首页任务进度统一使用全局进度归一化，避免 0.31 / 31 两种口径显示错误。
- “技术信息”继续按需展开，不抢占比赛主视觉。

### 仿真系统
- 保持“左参数 + 右大画布”。
- 光源、镜头、光纤、计算设置为左侧主类；更多设置默认收起。
- 耦合效率、系统效率、端面效率统一为主页面内联结果状态，不再存在数字效率独立弹窗。
- 参数修改后允许保留上一结果并显示“需更新”，不通过清空图形制造上下文断裂。
- 科研图可以独立弹出；支持缩放、平移、恢复、快照/跟随当前方案等既有能力。
- 显示设置与物理计算设置分离，窗口 resize 不应触发正式物理重算。

### 参数研究 / 参数优化
- 采用单页面纵向工作流，不再使用固定窄左栏承载大量变量。
- 默认只显示本次选择的研究参数；完整参数库按需打开。
- 参数响应结果支持用户明确确认后的“应用此参数”和“在此附近细化”。
- 优化设置按“目标/变量/约束/计算量”归类，高级算法继续折叠。
- 候选方案的参数明细和正式仿真状态不再作为独立一级页签。

### 容差分析
- 默认作为当前方案/候选方案的后续分析，在参数研究与优化页面原地展开。
- 完整深入分析仍可在该区域继续展开，但不会切断当前方案上下文。
- 容差分析不会未经用户确认自动启动。

### 实验验证
- 采用“上数据 → 计算并比较 → 下结果”的结构。
- 没有数据时不显示巨大空表，只显示简短空状态。
- 用户只需导入/录入参考数据；平台值由计算流程补充。
- AI上下文现在包含每个验证工况、参考值/平台值/不确定度/参数变化/诊断和比较指标。
- 修复 LazyResultWorkspace 缺少 current_data 导致 AI 读取验证当前图失败的静默问题。

### 模型分析
- 取消永久右栏，采用“模型摘要 → 全宽主图 → 详细指标”纵向结构。
- 没有可绘制数据时不显示巨大空画布。
- R²<0 显示明确“× 表现较差”，而不是只依靠红色。
- RF/XGBoost 与 BiLSTM 按不同应用场景呈现，不做不恰当的统一排名。

### SHAP / 失配诊断
- 单一纵向滚动页面，无固定高度内部滚动列表。
- 阅读顺序已修正为“主要物理因素 → 具体参数 → 当前方案 → 整体影响 → 物理依据”。
- 默认具体参数 Top 5；“展开全部因素”通过整页自然展开，不制造嵌套滚动。
- 全局重要性、当前正向贡献、当前负向贡献使用不同语义色，同时配合方向、数值和文字，不只靠颜色。
- 分析设置默认折叠；物理依据按需展开。

### 任务中心
- 保持“左任务列表 + 右详情”。
- 进度统一支持小数分数、百分数、百分号字符串三种来源。
- 同一任务进度单调不回退；终态后延迟 running 事件不允许重新打开任务。

### 教学中心
- 保留“大屏实验区 + 临时/悬浮窗口”。
- 分析/记录类低频功能已收进“方案”抽屉，不继续在实验画布底部常驻。
- 2D与3D使用同一个 ExperimentModel / TeachingSceneModel 状态。
- 3D当前实现使用 Qt Quick 3D View3D + PerspectiveCamera，而不是QPainter伪3D。
- 器件使用真实3D primitive；主光路使用真实3D Cylinder几何；Gaussian包络使用分段三维管状几何。
- 已补充射线—水平面交互拖动：拖动期间只本地更新3D器件位置，Gaussian包络暂时淡化；松手后一次性写回共享模型。避免拖动期间反复正式计算。

### AI助手
- 内置快捷问题：
  - 我现在应该怎么继续？
  - 解释当前结果
  - 当前结果可靠吗？
- AssistantResearchSnapshot 包含方案修订号、正式结果、当前页面/当前图、ResearchContext、全部 Findings、模型/数据集注册状态以及全部带结果任务。
- 任务和 Findings 使用 ID 字典保存，数量超过30时也不会只保留头尾而丢掉中间研究证据。
- AI“下一步”逻辑会读取当前模型测试R²；R²<0时优先提醒先确认模型可靠性，而不是让SHAP直接指导变量选择。
- AI只提供可选研究路径和依据，不会自动修改参数、自动采用方案或自动启动容差。

## 3. 进度条异常专项处理

统一函数支持：
- `0.31` → 31%
- `31` → 31%
- `31%` → 31%

并实现：
- 单个 job 的进度不允许倒退；
- completed 固定 100%；
- failed/cancelled 保留最后有效进度而不是跳回0；
- 终态之后的延迟 running 事件不会重新打开任务；
- 旧 job 的进度不会覆盖当前活动 job；
- 首页任务摘要、任务中心图表、模型训练、参数研究/优化使用同一归一化原则。

回归样例：`5 → 31 → (迟到18) → 100 → (迟到70)` 实际显示 `5 → 31 → 31 → 100 → 100`。

## 4. 字体、颜色和视频可读性

- 应用默认字号 12pt 以上（约16px级别），主导航与关键标题更大。
- 状态色均配文字/符号：例如 `✓ 已验证`、`⚠ 需更新`、`× 表现较差`、`— 未分析`。
- 高对比深蓝/深绿/深橙/深红用于语义状态；重要正文不使用低对比浅色字。
- 图表用颜色 + 方向/线型/标记 + 数字共同编码。
- SHAP中全局、当前正向、当前负向同时通过颜色和左右方向/符号表达。

## 6. 当前环境无法完成的视觉验证与明确边界

容器的 Qt offscreen/software 渲染后端不提供 Qt Quick 3D 所需的 QRhi/3D graphics API，因此 `View3D` 在此环境无法真正输出3D帧截图。当前已验证：
- QML状态为 Ready；
- 无QML加载错误；
- View3D/PerspectiveCamera代码实际存在；
- 节点、真实3D主光路、Gaussian包络数据均已进入QML bridge；
- 3D拖动的最终坐标映射信号通过回归。

真实3D视觉效果仍需在用户Windows GPU环境运行确认。这是容器图形后端限制，不是代码回退到贴图/QPainter。

尚未伪装为已完成的第二阶段能力：
- 可移动三维截面及 `I(x,y,z)` 放大窗；
- 光纤端面专用模场放大镜；
- 所有输入框的自由文本单位解析（如直接键入 `200 μm`）；
- 未闭环的自动可变结构候选生成。

这些功能不影响本轮核心页面结构、研究证据联动和真正Qt Quick 3D第一阶段落地。
