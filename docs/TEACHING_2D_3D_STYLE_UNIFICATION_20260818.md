# 教学中心 2D / 3D 视觉同源改造验收记录

日期：2026-08-18

## 本轮目标

教学中心此前已经让侧视、俯视、3D 共享 ExperimentScene、对象 ID、世界坐标和正式 raytrace，但 2D 仍沿用深色教学/CAD 画布与独立卡通视觉语言，切换到浅色 Quick3D 后仍像两套软件。本轮把“数据同源”继续收敛为“数据 + 视觉语义同源”。

## 已改

- 侧视改为与 Quick3D 相同的浅色世界背景和浅灰光学平台；器件底座落在由当前 ExperimentScene 主光轴实际位置推导的平台基准上，不再使用旧固定 y=430 背景基准。
- 俯视显示同一光学平台的面板/孔阵列工程投影；侧视与俯视不维护第二套器件布局。
- 删除穿过器件中心的高对比金属导轨，只保留与 3D 相同语义的浅灰光轴参考线。
- 2D 器件仍由 3D asset registry 的 `pick_scale` 和 kind 驱动轮廓尺寸，并按 Quick3D 器件视觉身份统一：浅色激光器、深灰镜架/仪器、灰色立柱/底座、青色玻璃、橙红正式光束。
- 2D 正式光束和 Quick3D 使用同一 `#D94801`；选择态统一为 `#155EEF`。
- 大块白色教学标签卡去除，改为轻量工程文字注释。

## 同源边界

“同源投影”不是把 3D 截图压扁，而是：

`ExperimentScene 世界坐标 -> 侧视/俯视正交工程投影`。

允许 2D 隐藏螺钉、倒角、背面旋钮等细节，但对象身份、位置、方向、支撑关系、选择状态和正式光线路径必须来自同一 Scene。
