# 界面重构验收结果（2026-08-17）

## 1. 本次已落地的界面结构

- 永久导航压缩为窄图标栏：工程、仿真、研究、教学。
- 点击图标后使用单层高密度功能抽屉，不再层层钻取页面。
- 中央使用多文档标签保留当前工作内容，打开新任务不会把已有工作直接覆盖。
- 右侧不再设置永久大栏；参数、教学提示等作为上下文信息按需出现。
- 底部只保留耦合效率、结果、数据、历史、任务等紧凑入口。
- 浮动智能助手保留，并继续作为辅助能力而不是一级模块。

## 2. 功能守恒与结果归组

原有结果目录的18项能力均保留：光路、三维光路、光束包络、点列图、MTF、PSF、焦面截面、光斑尺寸、振幅、相位、相位对比、多平面演化、光纤基模、端面匹配、XY模场比较、重叠贡献、能量分解、束腰位置。

这些能力不再全部平铺，而归入六类分析器：系统视图、光束传播、焦面分析、复光场、模场匹配、像质与波前。未计算的结果仍保留入口并显示“点此计算”，不再因为没有现成数据而从界面消失。

分析器内部增加关键指标条和折叠详情。例如点列图的RMS半径直接作为点列图指标；艾里斑半径只在后端确实提供该数据时显示，不伪造数值。

## 3. 机器学习链路

- “代理模型”聚合数据、训练、评价和模型应用入口。
- “正向预测”已设置明确入口，直接进入现有“预测当前方案”流程，并提示预测后进行正式仿真验证。
- “反向设计”已设置明确入口，进入现有优化/代理模型候选流程；平台不会擅自替用户决定哪些参数可调，而是要求确认目标和变量。
- 模型解释不再作为研究抽屉一级按钮；它应从模型评价或某次预测结果进入。

本次没有伪造新的机器学习算法：正向预测和反向设计复用了项目已有代理模型、优化和候选方案能力，并重新接通入口与工作流。

## 4. 教学界面

教学工作台的解释区域由接近半屏的第二主界面缩为430～500像素的上下文区，并可关闭。单项失配只直接显示“观察”和“修正”，更详细的原理、适用边界和实验判断折叠在“原理与验证”中。教学三维/光路因此获得更大的主显示面积。

## 5. 比较功能

仿真结果比较窗口已支持：

- 两项对比；
- 三项对比（一个主视图加两个参考视图）；
- 四项对比（2×2）；
- 五项及以上使用“焦点 + 参考”布局，避免继续把所有图等分到看不清。

当前版本尚未完整实现“任意跨页面文档统一加入比较集并同步/冻结参数状态”。该项明确保留为后续检查点，不计入本次完成项。

## 6. 字号与颜色对比度

- 应用字体基线：13.5 pt。
- 新壳层按钮、分析指标等不低于约12.5 pt。
- 静态计算得到的主要对比度：
  - 主文字 / 浅背景：16.96:1；
  - 次文字 / 白底：10.46:1；
  - 白字 / 主色：5.41:1；
  - 导航文字 / 深色导航底：13.23:1。

上述组合均超过4.5:1的常用正文对比度门槛。
