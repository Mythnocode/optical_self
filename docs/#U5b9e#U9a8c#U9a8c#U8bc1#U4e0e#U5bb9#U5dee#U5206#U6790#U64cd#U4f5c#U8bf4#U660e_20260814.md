# 实验验证与容差分析操作说明

## 1. 设计原则

本版本把“实验数据对比”和“容差/鲁棒性分析”并入 **研究与优化**，避免为 E003/E004/E006 或每一组实验单独编写脚本。

界面采用“默认自动、专家可接管”的渐进式设计：

- 普通仿真默认只选择 **预览 / 标准 / 高精度 / 研究级**；
- 接收面网格、分析光瞳采样、传播方法、零填充和初始计算窗口收进 **高级数值设置**；
- 关闭“自动选择网格与采样”后，高级用户仍可手动设置上述参数；
- “有效结果约占图像 2/3”只控制 **显示取景**，不缩小数值积分窗口；
- 计算域仍由边缘功率、自动扩展和收敛检查保护，避免为了显示美观裁掉 Gaussian 尾部。

## 2. 实验验证

路径：**研究与优化 → 实验验证**。

### 2.1 数据输入

支持两种方式：

1. **批量导入 XLSX/CSV**；
2. **手动添加**后在表格中编辑。

推荐列：

| 工况 | 参考值 | 参考不确定度 | 平台值 | 数值不确定度 | 输入参数不确定度 | 单位 |
|---|---:|---:|---:|---:|---:|---|

其中“参考不确定度”只填写来源明确的标准差/标准不确定度；如果论文只给出含义不明确的 ± 区间，应保留原文口径，不强行解释为 1σ。

### 2.2 E003

1. 在“仿真系统”建立对应光源、镜片与光纤工况；
2. 完成正式耦合计算；
3. 在“实验验证”选择 E003；
4. 选中目标行，点击 **写入当前正式结果**；
5. 若正式结果包含收敛变化量，会同步写入数值不确定度列；
6. 点击 **计算对比**，得到 RMSE、MAE、相对 RMSE、残差和误差条图。

### 2.3 E004 / E006

1. 在“规律扫描”中分别扫描光纤 X 偏移或 X 倾角；
2. 输出指标选择耦合效率；
3. 扫描范围应覆盖峰值两侧的 50% 交点；
4. 在“实验验证”点击 **从最近扫描提取 3 dB**；
5. 系统线性插值左右半高交点并计算全宽；
6. E004 自动换算为 μm，E006 自动换算为 mrad。

## 3. 容差分析

路径：**研究与优化 → 容差分析**。

支持：

- 名义方案：最近最优方案 / 当前项目；
- 常用装调误差快捷添加：dx、dy、dz、θx、θy；
- 正态 / 均匀 / 三角分布；
- Random / LHS / Sobol；
- 样本数与效率合格阈值；
- Monte Carlo 标准差、P05、合格率、有效样本率；
- 参数—响应相关性；
- 可选一阶确定性容差预算。

### 3.1 驻点警告

对耦合效率峰值附近的对称装调参数，局部一阶导数可能接近 0，因此一阶 RSS 预算可能严重低估二阶敏感性。

如果界面检测到：

- Monte Carlo/LHS/Sobol 标准差明显非零；
- 一阶 RSS 标准差远小于随机传播结果；

会提示：**鲁棒性判断优先采用随机传播标准差、P05 与合格率。**

## 4. 参数优化后的容差复核

“正式优化设置”新增：

> ☑ 优化完成后准备容差复核

默认开启。优化完成后：

1. 自动把最佳参数同步到容差分析页；
2. **不会自动启动** Monte Carlo，以免未经确认产生大量计算；
3. 用户检查制造/装调容差量级后，点击“运行容差分析”；
4. 容差结果会同步显示在参数优化的 **容差/鲁棒性** 页签；
5. 选择方案时建议同时看名义效率、标准差、P05 与合格率，而不是只看名义最优值。

## 5. 输入不确定度回填实验验证

完成容差分析后，在“实验验证”选中工况并点击：

> **写入容差标准差**

即可把输入参数随机传播得到的输出标准差写入“输入参数不确定度”列。

实验验证的合成标准不确定度按当前已量化分量计算：

\[
u_c = \sqrt{u_{ref}^2 + u_{num}^2 + u_{input}^2}.
\]

模型—实验残差不自动并入平台不确定度。

## 6. 数值策略

自动模式推荐值：

| 精度 | 接收面网格 | 分析光瞳 | 布局采样 | 零填充 |
|---|---:|---:|---:|---:|
| 预览 | 129 | 17 | 7 | 1.5× |
| 标准 | 257 | 49 | 9 | 2× |
| 高精度 | 513 | 65 | 13 | 2× |
| 研究级 | 1025 | 65 | 17 | 2× |

这些只是默认策略。关闭自动模式后，手动参数会保存并保持，不会被“实验验证 → 保存并应用到全局”重新覆盖。

- 手动添加实验数据；
- XLSX/CSV 批量导入；
- 诊断列显示/隐藏；
- 对比计算；
- 容差参数实体复选框；
- 非法数字输入拦截；
- 容差运行按钮重复点击防重提交；
- 容差标准差回填实验验证；
- 参数优化 → 容差分析快捷入口；
- 自动数值策略与高级设置切换；
- 手动网格/光瞳/传播方法保存后不被自动覆盖；
- 显示占比变化不改变数值计算窗口。
