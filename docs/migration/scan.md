# 扫描迁移记录（2026-10-02）

分支 `js`。完整迁移仍未完成，数据集优先 C++ 的实现和测量见 [datasets.md](datasets.md)。

## 实现

- `ScanView.vue` 替换占位页面，保持原版设置卡片、两列控件、范围表、运行按钮、进度、单曲线/热图工作区。
- 使用原版优化变量目录的顺序和标签，扫描仅取前两个勾选变量；范围初值使用原版两位小数及 ±10% 展示规则。
- 新 `/scan/prepare` 从完整 Simulation 请求生成原版扫描 payload，保留导入复场及计算选项。`/scan/jobs` 仍调用现有扫描服务和光学引擎。
- 范围、设置、任务编号和提交时的项目上下文持久化。项目变化时保留历史结果并提示；异步准备和绘图均有上下文/版本检查。
- 结果展示逻辑提取到 `shared_presentation/scan_results.py`，旧 Qt 入口保留兼容导入。曲线复用原版 Matplotlib 展示逻辑；热图复用已有 JS LUT，按原版像素宽高比和平滑插值显示。JavaScript 不计算光学响应。
- 修复旧“多参数采样”无效模式名称，接入既有 LHS，并以页面点数作为总采样数。对数尺度传入扫描请求，采样点使用 geomspace；原版此前静默使用 linspace。
- 自适应加密仍未实现，明确拒绝并提示用户选择线性/对数方式。扫描模式、范围、有限数值、点数和对数同号条件在提交前校验。
- 保留最多 8 个失败点的错误例子用于诊断。稀疏扫描结果若要求构造超过一百万格的热图，显示容量提示，计算结果不截断。
