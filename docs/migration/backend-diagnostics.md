# 后端连接与诊断（2026-10-02）

分支 `js`，完整迁移继续进行。数据集仍优先使用现有 C++ 追迹内核；本阶段没有改动光学计算或精度门槛。

## 实现

- Electron 定期检查已有连接；两次健康检查失败后显示故障状态。重连仍在运行但暂时无响应的自有后端时，等待该进程恢复，保留进程句柄和正在计算的任务。
- 启动与关闭使用生命周期版本，关闭后未结束的健康检查不能继续启动后端或发布旧的连接成功状态。旧子进程的退出回调不能覆盖另一个进程的状态。
- 浏览器预览每5秒检查健康状态。恢复连接时重新读取模型页的数据集列表及生成参数，编辑组件保持挂载。桌面和浏览器使用同一个连接状态。
- 故障面板提供重新连接、打开日志目录、复制诊断信息。浏览器预览没有本机日志目录入口，因此该按钮禁用；桌面通过现有受信任 IPC 打开日志目录和复制诊断。
- 故障面板为原生模态 dialog，可覆盖已打开的计算设置。连接恢复后关闭故障面板，设置草稿仍然保留。Escape 不隐藏故障入口；Tab 在可用按钮之间循环。
- FastAPI HTTP 日志记录请求编号、方法、路径、状态、耗时、任务编号。桌面 API 代理记录对应元数据和传输失败；浏览器内存保留最近40次请求，桌面诊断保留最近60个事件。
- HTTP 请求诊断不保存请求体、响应体、矩阵或查询参数。桌面报告还包含应用版本、平台、后端状态、日志路径和其他近期诊断事件。没有向外部服务上传。

后端 `elapsed_ms` 表示中间件收到响应头前的时间；桌面/浏览器表示接收和解析响应的时间。它们都不是数据集任务的总计算时间。
