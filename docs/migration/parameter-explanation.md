# 物理链路与单参数贡献迁移（2026-10-02）

分支 `js`；完整迁移仍在进行，当前系统解释后续证据见 `current-explanation.md`。

## 接通的工作流

- 原版参数栏、当前项目的19个参数行、筛选和镜头分组；模型选择与贡献排序独立。
- 原版“单参数贡献图 / 物理链路”切换、80样本SHAP依赖、无曲线提示。
- 贡献排名前3项默认勾选，最多3项；零项/单项/三项卡片、专属公式与共同输出公式。
- 公式链路超出窗口时滚动，支持键盘滚动；按模型保存任务与勾选，刷新恢复。
- 新增 `/models/{id}/shap/jobs` 和 `/explainability/jobs/{id}/parameter-presentation`。
  复用原有解释服务、后台任务、状态推送与轮询。同步入口保留。
- 缓存结果选择其它参数后点击计算，用现有结果重画；不重复提交相同解释任务。

## 计算及共享代码

原版物理链路的依赖值是训练特征的直接SHAP，不同于贡献排序中回传到设计变量的贡献。
两者口径保留，没有把贡献排序的归因矩阵替换进原版参数曲线。

- 实际页面随机森林任务 `job-bcb80a1e76d6`，模型 `model-63d9d3ea55cf`。
- 实际页面XGBoost任务 `job-7ed7bac4d440`，模型 `model-d8d744b63586`。
- 两任务均80样本且命中原服务缓存；不将0ms缓存耗时作为新计算性能结果。
  与原版同步接口比较仅排除耗时、缓存标志和新增任务包装，全部其余字段相等。
- 公式目录、特征绑定、建议和专属公式步骤从原版移动到 `explanation_formulas.py`，
  原入口兼容导入；公式PNG渲染提取到 `formula_images.py`。后端没有导入PySide。
- Qt与Web共用参数曲线载荷、排名文字、公式链路内容和散点绘图。
- 公式渲染明确使用原版字体配置。独立后端默认字体曾使传播公式高2px，已修正；
  现与Qt的公式源图尺寸相同。没有改动公式、模型预测或光学计算。
- XGBoost真实输出为 `coupling_loss_db`，曲线为SHAP(dB)，链路显示耦合损耗(dB)。
  原来的效率转换注释与实际原始数值不符，Qt与Web共享显示名已改为真实单位。
