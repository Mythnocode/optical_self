# 静默 Bug 修复说明

本次针对“界面没有报错，但结果已经不可信”的路径做了回归修复：

1. **数据集波长统一**：以 `project.source.wavelength_nm` 为权威值；兼容旧样本的顶层字段，但不再在缺失时静默回退到 1550 nm。项目、source 和 hybrid options 使用同一个有限正数波长。
2. **画布拓扑自愈**：新增 source 或删除中间节点后重新修复正式依赖边，避免结果节点看似存在、实际没有输入。
3. **增量计算保持增量**：进程内回退引擎接收当前节点请求的分析集合，不再把一次局部刷新扩大为全量计算。
4. **后端空响应不再冒充成功**：HTTP 结果缺少 `status=completed` 时转入回退流程并提示原因。
5. **失败结果保持可解释**：保留最后一次有效图和指标，同时清除运行态并标记结果过期；错误提示不会被后续成功摘要覆盖。
6. **SHAP 输入严格校验**：缺失特征、非数值和非有限值都明确报错，不再把缺失特征填成 0。

验证：纯 Python 回归测试通过；当前环境缺少 Qt 图形依赖 `libEGL.so.1`，因此未宣称完成本机 GUI 启动测试，目标机仍需运行完整 Qt smoke test。
