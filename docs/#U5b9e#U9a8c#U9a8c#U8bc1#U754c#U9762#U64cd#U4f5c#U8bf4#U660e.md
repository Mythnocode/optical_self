# 实验验证界面操作说明

## 一、设计原则

本版本将“普通操作”和“科研级数值控制”分层：

- 普通仿真默认使用“精度预设 + 自动选择网格与采样”，不要求用户理解接收面网格、光瞳采样和零填充。
- 高级用户可展开“高级数值设置”，手动指定接收面网格、布局采样、分析光瞳采样、传播方法、零填充和初始计算窗口。
- 实验验证中的数值策略可“保存并应用到全局”，使仿真系统使用同一套精度策略。
- 自动取景与数值计算域严格分开：自动取景只调整显示范围；计算域仍由后端自动扩展和收敛规则保证完整。

## 二、实验验证入口

进入：`研究与优化 -> 实验验证`。

实验验证支持：

1. E003 耦合效率；
2. E004 横向 3 dB 全宽；
3. E006 角度 3 dB 全宽；
4. 自定义指标。

参考数据类型可选择“实验数据”或“文献理论”。

## 三、批量导入

点击“批量导入 XLSX/CSV”。推荐字段：

- 工况
- 参考值
- 参考不确定度
- 平台值（可留空）
- 数值不确定度（可留空）
- 单位

系统同时识别常见别名，例如“实验值、文献值、理论值、标准差、SD、platform、simulation”等。

导入后可直接在表格中继续修改。

## 四、手动录入

点击“手动添加”，在表格中直接输入：

- 工况名称；
- 实验/文献参考值；
- 参考标准不确定度（若有明确统计意义）；
- 平台值；
- 数值不确定度；
- 单位。

“差值、相对误差、合成标准不确定度、归一化残差”由界面自动计算。

## 五、平台结果写入

### E003

1. 在“仿真系统”建立当前工况；
2. 运行正式光纤耦合计算；
3. 返回“实验验证”；
4. 选择对应行；
5. 点击“写入当前正式结果”。

若正式结果包含耦合收敛最后一级变化量，界面会同步写入“数值不确定度”列，作为数值收敛变化的记录。

### E004 / E006

1. 在“研究与优化 -> 研究与优化 -> 规律扫描”运行耦合效率一维扫描；
2. E004 扫描光纤 X/Y 横向偏移；E006 扫描光纤倾角；
3. 扫描范围必须覆盖峰值两侧的半高点；
4. 返回“实验验证”，选择对应工况；
5. 点击“从最近扫描提取 3 dB”。

系统使用线性插值寻找 `0.5 × 峰值` 两侧交点并计算全宽：

`W_3dB = x_right - x_left`

E004 自动换算为 μm；E006 自动换算为 mrad。

规律扫描结果页也新增“3 dB（50%峰值）”区间，不再需要外部脚本提取。

## 六、不确定度口径

当前实验验证页明确区分：

- 参考不确定度：实验或文献明确给出的标准不确定度；
- 数值不确定度：来自网格/采样收敛等数值变化；
- 残差：平台结果与参考值的差异。

如果同时填写参考标准不确定度和数值标准不确定度，界面按独立分量计算：

`u_combined = sqrt(u_reference^2 + u_numerical^2)`

并计算归一化残差：

`z = abs(platform-reference) / u_combined`

注意：若文献只写“±”但没有说明是标准差、标准误或置信区间，不应直接当作标准不确定度填写。

## 七、数值策略

实验验证页的“数值策略与不确定度”可以设置：

- 自动选择网格与光瞳采样；
- 精度预设：预览 / 标准 / 高精度 / 研究级；
- 是否运行采样收敛测试；
- 是否自动取景；
- 有效区域显示占比，默认约 67%。

点击“保存并应用到全局”后，当前打开的仿真系统会同步该策略。

自动模式推荐值：

| 精度 | 接收面网格 | 分析光瞳 | 布局采样 | 零填充 |
|---|---:|---:|---:|---:|
| 预览 | 129 | 17 | 7 | 1.5× |
| 标准 | 257 | 49 | 9 | 2× |
| 高精度 | 513 | 65 | 13 | 2× |
| 研究级 | 1025 | 65 | 17 | 2× |

这些是默认策略，不是物理常数。高级用户关闭自动模式后仍可在仿真系统的“高级数值设置”中自由修改。

## 八、为什么“有效结果占图面约 2/3”只用于显示

不能为了让光斑看起来更大而缩小数值积分窗口，因为这可能裁掉 Gaussian 尾部并改变功率积分和耦合效率。

因此本版本采用：

- 数值计算域：由初始窗口、后端边缘功率检查、自动扩展和收敛策略控制；
- 显示视口：根据有效强度/模场范围自动裁切，使主要结果约占图面 2/3。

用户关闭“结果图自动取景”后，可以查看完整计算范围。

## 九、推荐日常工作流

`建立/载入光路 -> 选择精度预设 -> 正式仿真或规律扫描 -> 实验验证 -> 导入/录入参考数据 -> 写入平台结果 -> 计算对比 -> 保存结果`

对于普通实验验证，不再需要为 E003/E004/E006 分别维护独立脚本；脚本仅保留给批量自动化、回归测试或特殊科研分析。
