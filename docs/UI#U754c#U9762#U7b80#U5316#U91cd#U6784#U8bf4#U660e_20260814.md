# UI 界面简化重构说明（2026-08-14）

## 目标

本轮不删除计算能力，而是减少常驻信息，采用“常用操作直接显示、低频设置折叠、详细结果按需展开”的界面结构。首页保留比赛展示用主图。

## 统一原则

- 默认只显示完成当前任务真正需要的参数和结果。
- 低频参数放入“更多设置 / 高级设置”。
- 复杂结果放入“详细结果”，避免空卡片和大量“—”长期占位。
- 不用“研究级”等模糊等级；采样设置优先显示实际数字，例如 `257×257`、`513×513`。
- 界面用科研人员常用表述，避免“正式复核”“鲁棒性复核”等不自然词语。
- 不加入 ROC、混淆矩阵；当前回归模型优先展示预测一致性、残差、特征重要性和可靠性。
- RF/XGBoost 与 BiLSTM 按应用场景分开说明，不做误导性的统一模型排名。

## 首页

- 保留比赛展示用平台流程大图，资源文件未删除。
- 仅清理部分生硬表述；“研究与优化”说明改为参数扫描、方案优化与容差分析。

## 仿真系统

### 常用操作

主工具栏只保留：

- 自动预览
- 编辑光路
- 预览
- 开始计算

低频的保存、教学参数导入、多路径等仍然保留在详细/高级区域。

### 参数

光源首屏只显示常用字段：

- 光源模式
- 主波长
- 束腰半径
- 束腰位置
- M²
- 分轴设置

下列内容移入“更多设置”：

- NA
- 视场
- 辅助波长
- 功率
- 温度/压力
- 材料补偿
- 物距/入瞳/像面位置

光纤首屏保留模式、模场/NA以及位置和角度；光纤长度、衰减、连接器损耗等移入“传输设置”。

### 数值设置

默认使用数字网格预设：

- 129×129
- 257×257
- 513×513
- 1025×1025

自动模式会显示实际使用的接收面网格和光瞳采样。具体传播方法、零填充、计算窗口等进入“高级设置”。

### 结果

常驻结果视图缩减为：

- 光路
- 点列图
- 焦面光斑
- 模场匹配

其他图仍可从结果下拉框进入，不删除。

在窄屏下只保留最核心的耦合效率摘要，避免系统效率、端面效率和耦合效率同时挤在一行。

焦面搜索不再作为普通仿真中的常驻分析，而在参数研究中提供快捷入口。

## 参数研究与优化

- 参数研究和参数优化使用同一页面、同一套研究对象和参数选择。
- 分析方式只在“参数研究 / 参数优化”之间切换。
- 计算量直接显示数字：研究为 31/81/161 点，优化为 80/300/800 次。
- 焦面搜索作为“常用研究”快捷入口。
- 右侧常驻信息只保留耦合效率、相比当前、仿真验证和主要后续操作。
- 容差分析不再作为一级页面，而是当前方案/优化方案的后续分析。
- 1366×768 等窄屏隐藏右侧摘要时，主结果下方会自动出现紧凑摘要和“容差分析”入口。

## 容差分析

默认只显示：

- 当前方案
- 参数模板
- 样本数
- 效率阈值
- 开始分析

容差参数表和采样方法放入折叠区。结果首屏只保留：

- 平均效率
- 标准差
- P05
- 达标比例
- 效率分布图

其余统计进入“详细结果”。

## 实验验证

- 支持批量导入和手动录入。
- 默认表格只显示工况、参考值、平台值、差值。
- 不确定度等列通过“详细数据”显示。
- 默认结果只显示 RMSE、MAE、相对 RMSE 和参考值/平台值主图。
- E003 使用当前计算结果；E004/E006 可使用最近扫描得到的 3 dB 全宽。

## 智能分析

首先区分模型应用场景：

- 固定结构参数模型：RF / XGBoost
- 可变结构模型：BiLSTM

默认分析视图：

- 预测一致性
- 残差
- 特征重要性

右侧只保留预测可靠性、R²、RMSE、是否超出训练范围和完整仿真状态。训练、数据集、模型版本放入“高级信息”。

数据集生成的数值等级也改为实际采样网格 `129×129 / 257×257 / 513×513`。

## SHAP

无分析结果时，只显示分析设置和主图空状态，不再显示大量空的解释卡片。

分析完成后按需出现：

- 主要因素
- 整体影响
- 当前方案
- 当前参数对应的公式
- SHAP 贡献
- 物理关系
- 下一步
- 预测可靠性
- 完整仿真状态

默认不常驻长篇文字解释，也不常驻低频内部字段。

## 用词调整

界面优先使用：

- 完整仿真
- 仿真验证
- 容差分析
- 预测可靠性
- 是否超出训练范围
- 采样网格
- 更多设置 / 高级设置 / 详细结果

兼容旧项目所需的旧字符串可能仍保留在内部映射中，但不作为新界面默认文字。
