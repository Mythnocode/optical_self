- 鼠标关闭自动模式后，高级参数启用；
- 鼠标展开“高级数值设置”；

发现并修复：自动网格复选框曾在表单中横向占满整行，点击文字右侧大块空白不触发；现在控件宽度按实际内容收缩，降低无效点击区域。

## 4. 容差后端回归

使用单一 `receiver.offset_x_mm` 正态容差、LHS 32 样本：

- 状态：completed；
- 接受样本：32/32；
- 唯一响应：32；
- 输出标准差：约 `6.3374e-4`；
- 随机样本响应不再被缓存名义值覆盖。

同时，名义点位于对称峰值附近时，一阶有限差分 RSS 可能为 0，而随机传播标准差非零。界面已加入驻点低估警告，提示优先使用 Monte Carlo/LHS/Sobol 的标准差、P05 与合格率。
