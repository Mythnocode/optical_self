# 柱面镜实现说明

## 参数约定

- `surface_type = "cylindrical"`（界面名称为“柱面”）。
- `cylinder_axis_deg` 是局部横向 `x-y` 平面内的柱轴，即零光焦度轴。
- `0°` 表示柱轴沿局部 `x`，曲率作用于 `y`；`90°` 表示柱轴沿局部 `y`，曲率作用于 `x`。
- 曲率半径、圆锥系数及偶次非球面系数沿功率子午面使用，与球面参数的单位一致。

## 几何公式

令柱轴方位角为 `a`，功率方向单位矢量为

`p = (-sin(a), cos(a))`。

局部横向点 `r = (x, y)` 在功率方向的有符号坐标为 `u = p·r`。柱面矢高只依赖 `|u|`：

`z(x,y) = sag(|u|)`。

因此沿柱轴移动时 `u` 不变，矢高不变。表面法向由隐式面
`F(x,y,z)=z-sag(|u|)=0` 的梯度得到：

`n ∝ (-sag'(|u|) sign(u) p_x, -sag'(|u|) sign(u) p_y, 1)`。

求交采用顶点平面初值和 Newton 迭代，Jacobian 中使用
`du/dt = p·d_xy`。折射继续使用矢量 Snell 定律，所以 45° 等斜置柱轴会自然产生 x/y 交叉耦合。

## 双轴近轴与高斯光束

柱面的近轴光焦度是二维张量。对于界面已有的独立 x/y Q 参数传播，两个子午面的有效曲率为：

- `c_x = c * p_x²`
- `c_y = c * p_y²`

对应折射矩阵中的 `C = -(n₂-n₁)c_axis`。0° 柱轴时 x 子午面 `C=0`、y 子午面为完整柱面光焦度；90° 时相反。机器学习耦合物理特征现在分别使用 x/y 系统矩阵，因此柱面造成的椭圆光斑及两个方向不同的波前曲率可进入耦合效率特征和后续 SHAP 分析。

斜置柱面的精确交叉项由正式二维光线追迹处理；x/y 独立 ABCD 是其对角近轴近似。

## 验收

`tests/test_cylindrical_surface.py` 检查：

1. 同一功率坐标、不同柱轴坐标的交点矢高相同；
2. 0° 柱面只弯折 y 子午面；
3. 90° 柱面将功率方向切换到 x；
4. x/y ABCD 光焦度符合 `(n₂-n₁)/R`；
5. 45° 柱面同时产生 x/y 方向分量。

紧凑批量追迹器尚未宣称支持柱面时会自动回退到正式完整追迹器，不会把柱面误算成球面。
