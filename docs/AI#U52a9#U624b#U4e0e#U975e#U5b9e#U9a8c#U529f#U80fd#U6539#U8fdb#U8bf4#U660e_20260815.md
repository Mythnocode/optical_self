# AI助手与非实验功能改进说明（2026-08-15）

## 本轮范围

本轮明确冻结“实验验证”功能，不修改实验验证页面、实验数据解析或后端验证接口。主要改进 AI 助手、可变结构候选、教学中心 3D 第二阶段、统一单位输入与静默异常可见性。

## 1. AI助手：从固定问答升级为研究状态评估器

新增 `ResearchAdvisor`，把研究证据、正式物理结果、代理模型、SHAP、任务结果和方案修订状态统一组织后再回答问题。

### 1.1 可回答的研究问题

- 我现在应该怎么继续？
- 解释当前结果 / 为什么效率低？
- 当前结果可靠吗？
- 当前主要问题是什么？
- 总结当前研究状态
- 哪些结果需要更新？
- 当前证据链是什么？
- 模型还能用于 SHAP 吗？
- 可以定型/采用当前方案吗？
- 当前证据是否冲突？
- 哪些参数值得优先研究/优化？
- AI助手能做什么？
- 直接询问某个具体参数时，自动检索该参数对应的当前 Findings。

### 1.2 证据等级与方案修订

AI 不再把所有结果视为同等可信。它区分：

1. 当前正式物理结果与数值诊断；
2. 正式参数扫描、容差等物理研究证据；
3. 已通过独立测试门控的代理模型；
4. SHAP 等模型解释；
5. 已属于旧方案的“需更新”结果。

旧方案 Findings 会自动从当前结论中排除，但仍保留作历史比较。Finding 和任务结果按 ID 保存，不再因为数量超过 30 条而只保留头尾。

### 1.3 模型可靠性门控

AI 会读取当前模型真实独立测试指标：

- 缺少测试 R²：证据不足，不使用模型指导研究；
- R² < 0：模型表现较差，禁止把 SHAP 当作当前参数依据；
- 0 ≤ R² < 0.60：仅探索使用；
- 0.60 ≤ R² < 0.80：可做辅助筛选，仍需正式仿真；
- R² ≥ 0.80：可做辅助筛选，不能替代正式仿真；
- 当前方案超出训练域：阻止模型/SHAP用于决策；
- 如果高效率区 RMSE 显著高于全局 RMSE，即使整体 R² 较高也会降级提醒。

重要原则：代理模型只是辅助证据。模型缺失、较差或域外时，AI 会排除机器学习证据，而不会反过来否定已经通过数值诊断的正式物理结果。

### 1.4 正式结果可靠性

AI 会检查：

- 正式结果是否对应当前方案；
- 是否收敛；
- 采样收敛检查；
- 传播采样检查；
- 窗口边缘能量检查；
- 能量闭合检查；
- 最佳焦点是否落在扫描边界。

### 1.5 证据冲突检测

同一参数的结构化趋势会按“正向 / 负向 / 基本不变”做语义归一化。类似“增加”和“正相关”不会被误判为冲突；真正相反的趋势会提示优先用正式扫描/正式仿真复核。

### 1.6 上下文完整性

AI 快照继续包含：方案修订、正式结果、当前图、ResearchContext、全部 Findings、模型/数据集、全部带结果任务；新增上下文采集错误记录。某个页面或注册表读取失败时，不再静默伪装成“没有数据”，AI 会明确降低判断强度。

### 1.7 权限边界

AI 可以解释、比较、给出研究优先级和下一步建议，但不会自动：

- 修改光学参数；
- 缩小扫描/优化范围；
- 采用候选方案；
- 启动耗时任务。

## 2. 可变结构候选：补齐 BiLSTM 发现与筛选链路

### 2.1 修复结构模型不可发现问题

BiLSTM 结构模型实际保存在独立 `structure_models` 目录，原普通 `/models` 注册表无法可靠发现。新增：

- `GET /api/v1/structure-models`
- 独立扫描结构模型 `manifest.json`
- 前端结构模型下拉列表与自动发现

### 2.2 新增结构候选接口

新增：

- `POST /api/v1/structure-models/{model_id}/candidates`

根据训练词表、元件数量范围与目标指标生成有限候选池，由 BiLSTM 排序。默认门控要求目标独立测试 R² ≥ 0.60，否则直接阻止候选排名。

### 2.3 不伪造“完整镜片处方”

当前功能明确限定为 `structure_sequence_only`：

- 比较元件数量/顺序；
- 如果未提供数值模板，使用训练集均值数值特征；
- 输出只标记为“预测筛选”；
- Finding 中 `verified=false`；
- 不自动应用到当前方案；
- 必须经过工程约束和正式复场仿真后才能成为有效候选。

这一步完成了“已有 BiLSTM → 结构序列候选筛选”的前后端闭环，但不是任意商业镜片处方自动生成器。

## 3. 教学中心 3D 第二阶段

在原有真实 `Qt Quick 3D View3D + PerspectiveCamera` 基础上增加：

### 3.1 可移动三维截面 I(x,y,z)

- 截面不再局限于最后一段光路；
- 沿通向光纤的完整有效光路连续移动；
- 跨多段光路按累计路径长度映射；
- 同步显示当前光束半径与理想光束半径；
- 截面位置、朝向随三维光路变化。

### 3.2 截面光强可视化

QML 中加入二维 Gaussian 截面 Canvas：

- 当前光束强度分布；
- 理想半径轮廓；
- 截面中心参考线。

### 3.3 光纤端面模场放大镜

新增端面放大视图，对比：

- 当前入射 Gaussian；
- 目标光纤模式近似；
- 当前接收效率。

教学数据仍明确属于教学近似，不冒充正式复场科研结果。

## 4. 统一单位输入

新增中央单位解析与 `UnitAwareDoubleSpinBox`，核心参数输入可接受显式单位，例如：

- `200 μm`
- `0.2 mm`
- `780 nm`
- `10 mrad`
- `1 deg`
- `31%`

内部仍转换为控件设定的标准单位。当前覆盖长度、角度和百分比，并应用到仿真核心参数、参数扫描、优化变量、工程约束和容差阈值。实验验证控件本轮保持不变。

## 5. 静默异常治理

本轮没有机械删除所有 `except/pass`，而是优先处理会影响科研判断的静默失败：

- AI 页面上下文读取异常；
- 任务结果读取异常；
- 当前模型/数据集注册表读取异常。

这些异常现在进入 `context_collection_errors` 并显示在 AI 判断中，不会被误认为“确实没有研究数据”。

## 6. 本轮未做的事项

- 实验验证增强：按用户要求冻结；
- E005/UCF 接入实验验证：本轮不做；
- 任意商业镜片数据库自动生成完整物理处方：本轮只做到结构序列筛选；
- 容器内真实 GPU 3D 帧截图：当前 offscreen/software Qt 环境不支持 QRhi/3D Graphics API，Windows 正常显卡环境仍需视觉验收。
