# 界面重构功能资产与归位（2026-08-17）

## 1. 重构原则

本次重构固定以下五条原则：

1. 围绕光纤耦合问题组织功能。
2. 功能服务于任务，不按源码模块堆菜单。
3. 智能能力作为辅助；训练、预测、反向设计必须接回正式仿真与工程参数。
4. 教学与科研共用底层模型和结果，但各自采用合适的表达，不互相抢主画面。
5. 主内容优先；大图进入中央视图，次要数值、说明和低频操作折叠。

同时增加一条界面硬规则：**物理对象、计算方法、结果视图、用户任务、辅助信息不得混在同一级导航。**

## 2. 呈现级别

| 呈现级别 | 规则 | 典型内容 |
|---|---|---|
| 主分析器 | 能独立承担主要观察任务 | 系统视图、光束传播、焦面分析、复光场、模场匹配、像质与波前 |
| 子视图 | 同一数据的不同观察方式 | 二维/三维、强度/振幅/相位、入射场/基模/对比 |
| 关键指标 | 一两个数值即可表达 | 束腰位置、光斑半径、耦合效率、RMS 半径、艾里斑半径 |
| 折叠详情 | 专业但非每次必看 | 能量分解、数值说明、适用边界、更多统计 |
| 低频动作 | 不应长期占屏 | 导出、截图、设置基线、保存快照、更多设置 |

## 7. 全局界面归位

- 永久左栏：仅四个图标入口——工程、仿真、研究、教学。
- 点击图标：打开单层、分组、紧凑功能抽屉，不做多级目录钻取。
- 中央：主内容和文档标签；大图、大曲线、教学三维、正向预测/反向设计结果均在中央工作。
- 右侧：不永久存在；只在需要编辑当前对象/当前任务设置时出现。
- 底部：结果、数据、历史、任务等低占用信息；默认折叠。
- 智能助手：保留浮动入口，不占固定边栏。
- 比较：2 项平铺、3 项“1 大 2 小”、4 项 2×2、5 项以上“焦点 + 参考”。
