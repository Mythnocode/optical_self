# 3 分钟演示流程内置资产与物理验证

## 演示资产

- 系统：780 nm 四透镜 + 780-HP（MFD 5.0 μm, NA 0.13）
- 光源：X/Y 束腰 893/1050 μm，M²-X/Y=3.05/1.33
- 数值策略：257×257，光瞳49，缩放 Fresnel，输出范围0.024 mm，padding 2
- 内置训练集：139 点（128 LHS + 11 个 X=0 的正式轴向扫描锚点）
- 输入：光纤横向位置 X、光纤轴向位置 Z
- 目标：模式耦合效率（不是总耦合效率）
- 内置参考模型：随机森林 300 树，独立测试 R²=0.94022

## 真实流程复核

| 环节 | 实际结果 |

## SHAP 物理一致性

全局重要性：轴向位置 Z > 横向位置 X。该排序与演示参数范围一致：Z 扫描 ±50 μm，而 X 仅 ±2 μm。

- `|X|` 与 X 对应 SHAP 贡献的 Spearman ρ = −0.9523（p≈1.65e−72）
- `|Z|` 与 Z 对应 SHAP 贡献的 Spearman ρ = −0.8781（p≈1.08e−45）

因此，横向偏移和轴向离焦越大，模型对模式耦合效率给出的贡献越负，符合高斯模式横向失配及离焦降低复重叠的物理趋势。

录像建议优先展示“主要因素 / 整体规律 / 单参数规律”。“当前系统”瀑布图的基准是**模型平均基准**，不是理想光学状态，不能把局部 SHAP 正负直接解释成相对理想状态变好/变坏。

## 3D 数据源

基准正式 raytrace 返回 1793 条真实光线路径，每条10个路径点。教学 ExperimentScene 只从这些正式光线中抽取最多9条真实代表光线用于可读显示；没有正式 raytrace 时不画物理光束，不使用器件拓扑吸附连线。

当前容器没有真实 QRhi/Quick3D GPU，因此最终视频中的真实 3D 视觉效果仍需在录制 Windows/GPU 机器上做最终 PASS 验收。
