## 4. SHAP 内容缓存失效规则复检

对安装到全新用户目录的示例模型执行：

1. 原始内容请求：命中缓存；
2. 只修改 `manifest.json` 文件时间戳、不改内容：仍命中缓存；
3. 真正修改 manifest 内容：旧缓存立即失效，`cache_hit=false`，本次重新解释约 176 ms；
4. 恢复原始文件内容：重新命中原有内容摘要对应缓存。

结论：持久 SHAP 缓存以内容摘要为依据，不依赖 ZIP 解压后的时间戳；真实文件内容变化会可靠失效。
