# UI 用户友好与 AI 研究联动改进说明（2026-08-15）

本轮基于 `ui_research_workspace` 继续重构，目标不是增加更多页面，而是降低新用户的认知负担，并把已经存在的分析结果真正接入 AI 研究助手。

## 1. AI 助手快捷问题与研究上下文

AI 助手输入区新增三个固定快捷问题：

- `我现在应该怎么继续？`
- `解释当前结果`
- `当前结果可靠吗？`

用户不需要反复输入长问题。AI 回答会读取：

- 当前页面与当前正在看的图；
- 当前方案修订号；
- `ResearchContext`；
- `Findings`；
- 当前正式仿真摘要；
- 当前模型/SHAP 页面上下文。

“我现在应该怎么继续？”不会给唯一命令，而是按研究目的给出最多三条可选路径，并说明每条路径用于解决什么问题。AI 不会自动修改参数、缩小搜索范围、应用方案或启动任务。

模型测试 `R² < 0` 时，AI 会优先提示模型当前不宜单独用于指导 SHAP/参数选择，而不是继续基于 SHAP 强推下一步。

## 2. ResearchContext / Findings 状态

保留并进一步接入统一研究上下文：

- `当前`
- `已验证`
- `需更新`

物理方案发生变化时，旧分析证据自动标记为 `需更新`。AI 不会把旧证据当作当前事实使用。

参数研究页的“已有分析”只提供证据，不自动替用户选择变量或范围。

## 3. 默认简洁、按需展开

### 参数研究与优化

默认只显示本次已选择的研究参数。完整的光源/镜头/光纤参数列表只有点击 `选择研究参数` 后才出现。

已有 SHAP/参数扫描证据只作为参数旁的小标签出现，不做“平台推荐 Top 3”。

### 模型分析

采用单一纵向滚动工作流：

`当前任务 -> 模型摘要/可靠性 -> 全宽主图 -> 详细指标`

固定结构 RF/XGBoost 与可变结构 BiLSTM 的用途区别仍保留在模型管理提示中，但不占新用户首屏。

### SHAP

采用单一纵向滚动工作流。默认保留模型、数据、对象和开始分析；分组、显示数量、范围、背景样本等收进 `分析设置`。

物理依据继续按需展开，不把长解释常驻首屏。

## 4. 语义颜色、字体与录屏可读性

- UI 默认字号提高；标准显示约 13.5 pt，大显示约 15.5 pt。
- 输入框、按钮、页签同步增高，避免只放大文字导致拥挤。
- Matplotlib 全局标题、轴标签、刻度和图例字号提高。
- 关键 UI 颜色对白底对比度回归均 >= 4.5:1。
- SHAP 图不再用“错误红/成功绿”表达贡献方向：
  - 全局重要性：蓝色；
  - 当前正向贡献：橙色；
  - 当前负向贡献：青色；
  - 正负同时由左右方向和带符号数字表达，避免只依赖颜色。

## 5. 结果与可靠性放在一起

仿真正式状态徽标与耦合效率/系统效率等关键指标放在同一结果条中，不再使用系统效率或端面效率独立浮窗。

模型分析将 `R²` 与语义状态直接关联：

- `R² < 0` -> `× 表现较差`
- `R² >= 0.8` -> `✓ 表现较好`
- 其余 -> `⚠ 需要结合误差判断`

RMSE 在没有用户目标阈值时不会仅因数值大小自动染成“失败”。

## 6. 图窗、锁定快照、图上研究

保留上一版已经实现的科研图窗：

- 自由移动/调整尺寸；
- 缩放、平移、1:1、恢复；
- 跟随当前方案；
- 锁定快照；
- 同一种图可打开多个窗口进行方案比较。

参数响应图继续保留：

- 点击已有扫描点；
- `应用此参数`；
- `在此附近细化`。

这些操作必须由用户明确确认，不会因 SHAP/扫描证据自动执行。

## 7. 页面状态保持与工作恢复

参数研究、模型分析、SHAP 的纵向滚动位置会保存并恢复。页面本身的当前选项/图仍由持久页面实例保持。

新增轻量工作恢复：

- 仅在存在未保存工作时去抖保存；
- 保存项目输入、研究上下文、Findings 等轻量数据，不写入大型结果数组；
- 下次启动只弹出“是否恢复”，绝不静默覆盖当前项目。

已有镜头编辑 Ctrl+Z / Ctrl+Y、教学工作台撤销/重做和项目 `*` 未保存标记继续保留。

## 8. 单位与输入合法性

参数研究的受控输入会根据研究变量显示对应单位：

- 波长：nm
- MFD：μm
- 倾角：°
- 空气间隔/位置等：mm

增加常见错误校验：波长/MFD 必须为正，空气间隔下限不能为负，扫描终点必须大于起点。

本轮没有实现任意自由文本（如 `0.2 mm`、`200 μm` 混输）的通用单位解析器；当前采用受控数值控件 + 明确单位，避免把未完成能力包装成已完成。

## 9. latest-wins、缓存与局部刷新

继续沿用并保留已有的：

- 仿真结果缓存；
- 预览 generation/latest-wins；
- 教学 2D/3D settled 更新；
- SHAP/模型按当前视图生成；
- 图窗读取共享结果而不是因 resize 重跑物理计算。

本轮重点是把这些机制保留在新的简洁界面中，而不是为了视觉重构退回同步全量刷新。

## 10. 容差模板

原有 `常用装调 / 优化参数+常用装调 / 自定义` 等模板继续保留。LHS、Sobol、随机种子等高级内容不提升到默认首屏。

## 11. 教学中心 3D

保留“大屏 + 悬浮/边缘工具”的教学工作台结构。

当前 3D 空间视图新增/强化两层可读的传播信息：

- 高对比橙色主光线：强调传播路径；
- 半透明青色 Gaussian 包络：强调光束尺寸/聚焦变化。

拖拽期间优先显示主光线保证跟手，settled 后恢复 Gaussian 包络，继续遵守“视觉跟手与正式物理结果分离”。

注意：当前教学 3D 仍建立在现有空间绘制工作台上，本轮没有把整个器件系统迁移为 Qt Quick 3D 的真实网格/光束 Geometry。若后续要实现真正三维 Gaussian 管状 mesh、光纤端面放大和移动截面，应作为下一阶段单独迁移，避免破坏已经稳定的拖拽和教学逻辑。
