# UI 层级合并重构说明（2026-08-15）

本轮目标不是继续增加折叠区，而是合并同一任务中重复的层级，减少未运行时的空卡片、重复入口和低频设置常驻。

## 参数研究与优化

- 将“分析方式、研究对象、研究目标、研究参数、计算量”合并为一张连续的“研究设置”。
- 参数研究与参数优化共享同一套研究参数和范围。
- 焦面搜索作为参数研究快捷预设，不再独立占一块。
- 未运行时隐藏详细结果和结果摘要；产生结果后再显示。
- 扫描/优化低频选项统一放入“更多设置”。
- 可变结构只展示当前已经闭环的已有结构预测/比较能力，不再把未来自动结构生成能力做成可点击约束。

## 仿真系统

- 镜头编辑入口去重，保留镜头区中的完整编辑入口。
- “设置”只负责计算设置；结果显示控制回到结果区。
- 常用结果保留：2D 光路、3D 光路、点列图、焦面光斑、模场匹配。
- 采样直接使用 129×129、257×257、513×513、1025×1025 等数字表示，不使用“研究级”等等级名称。
- 耦合效率作为首要结果；其他效率和诊断进入详细结果。

## 实验验证

- 将数据导入、平台计算和结果比较合并为一条流程。
- 默认只导入参考/实验数据，不要求导入平台值。
- 主按钮统一为“计算并比较”，调用平台计算后自动回填平台结果并计算误差。
- 数据操作和数值设置收进折叠区；不确定度和逐点诊断按需展开。

## 首页

- 比赛展示主图保留。
- 删除重复的功能入口、结果来源说明和质量说明层级。
- 首页保留当前项目和少量核心快速入口。

## 模型分析与失配诊断

- “智能分析”改为“模型分析”，“智能失配诊断”改为“失配诊断”。
- 模型分析把当前任务和模型场景合成一个上下文，不再单独占大卡片。
- SHAP/失配诊断以分析为主任务，报告改为次级入口。
- 物理依据、公式和当前因素放在同一分析链路中，详细内容按需展开。

## 任务中心

- 取消重复的任务状态环形图、“需要处理”、独立历史区和下方详情区。
- 合并为“任务列表 + 右侧详情”，通过状态筛选查看运行中、等待、完成、失败等任务。

## 教学中心

- 学习路线、进度和课程入口合并为一条学习路线。
- 具体教学实验过程保持原有分工，不做过度合并。

## 保留的既有修复

- AI 悬浮按钮支持简单拖动，不增加边缘吸附等额外功能。
- 启动时不再出现无内容的小顶层窗口。
- 3D 光路保持为常用结果入口。
