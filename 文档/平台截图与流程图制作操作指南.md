# 平台截图与流程图制作操作指南

本文对应研究报告第 4、5 章中已预留的图位。图 5-1 至图 5-6 均由平台实际界面获得；图 4-1 至图 4-4 是“开发架构/计算流程图”，应在 Word 中用形状绘制，不应伪装为平台截图。

## 1. 截图前的准备

1. 正常启动平台。你的日常入口 `app.py` 是正确的；若尚未启动，进入项目根目录后，用已安装依赖的 Python 环境运行：

   ```powershell
   python .\app.py
   ```

   `app.py` 会检测或启动后端，再打开桌面前端。后续仍需要在界面中选择“内置”并点击“开始训练”。

   如果模型页没有出现“内置演示·780 nm 四透镜八变量”，关闭平台后改用一次演示入口：

   ```powershell
   python .\tools\run_demo.py
   ```

   演示入口会安装包内真实演示数据、模型和 SHAP 缓存，但同样不会自动替你采用数据集或模型。

2. 将平台窗口最大化。推荐屏幕分辨率为 1920×1080；若使用 1366×768，请只截取主工作区，不要截进桌面、聊天软件或无关窗口。
3. 截图前确认页面不是“正在计算/训练中”，而是显示“正式计算完成”“训练完成”或“优化完成”。不要把加载中的空图、报错弹窗或调试终端放进报告。
4. 使用 `Win + Shift + S`，选择“矩形截图”或“窗口截图”，保存为 PNG 原图。建议统一命名为 `fig5-01-home.png`、`fig5-02-teaching-a.png` 等；不要经过微信压缩。
5. 对于需要同时展示两个结果的图，按下文分别截取 A、B 两张图，再在 Word 中用一个**无边框的 1×2 表格**并排放置；整组图只保留一条总题注。

## 2. 图 5-1：首页五大功能区总览

**题注：**图5-1 首页“光学研究工作流”五大功能区总览

### 平台操作

1. 点击左侧或顶部的“首页”。
2. 确认中央标题为“光学研究工作流”。
3. 将窗口拉宽，确保同一屏能完整显示五栏：**教学、仿真、模型、优化、解释**。
4. 每栏至少应能看到其主要卡片，例如教学中的“教学实验台”、仿真中的“搭建系统”、模型中的“准备数据集”、优化中的“优化变量”、解释中的“贡献排序”。
5. 截取整个工作流主区域，保留页面标题和五栏卡片，不要只截其中一栏。

### 截图检查点

- 五个功能区必须同时出现。
- 画面中不要有下拉菜单、悬浮提示或鼠标遮挡标题。
- 此图不需要先运行仿真或训练。

## 3. 图 5-2：教学模块中的器材、四透镜方案和耦合结果

**题注：**图5-2 教学模块中的器材拖拽、四透镜模型和即时耦合结果

本图建议由两张子图组成：`(a) 教学实验台与四透镜方案`、`(b) 成像与耦合结果`。

### A 图：教学实验台与四透镜方案

1. 从首页点击“教学”栏中的“教学实验台”。
2. 点击工具栏“方案”，选择 **“四非球面 · 780 nm 高效耦合”**。状态栏出现“已载入四非球面 · 780 nm 高效耦合演示”即可。
3. 如需体现器材操作，点击“器材库”，展示激光器、透镜、光纤等器件入口；也可以从器材库拖动一个器件到实验台后再截取。
4. 返回实验台主视图，确保能看到光源、四片透镜和光纤的整体布局。
5. 截图保存为 `fig5-02-teaching-a.png`。

### B 图：成像与耦合结果

1. 在相同教学方案下点击“成像与耦合”。
2. 在弹出的分析窗口中点击“开始计算”。
3. 等待状态显示“正式计算完成”。
4. 截取分析窗口中同时包含光斑/成像摘要、模式耦合效率和总耦合效率的位置，保存为 `fig5-02-teaching-b.png`。

### Word 拼图方式

将 A、B 图以 1×2 无边框表格并排，上方或图内分别标注“(a) 教学实验台”“(b) 成像与耦合结果”；整组下方只保留题注“图5-2 …”。

## 4. 图 5-3：建模模块的数据源与联合训练结果

**题注：**图5-3 建模模块的数据源选择与联合训练结果

本图建议由两张子图组成：`(a) 内置数据源`、`(b) 训练结果`。

### A 图：选择演示数据集

1. 从首页点击“模型”栏中的“准备数据集”。
2. 保持“数据来源”为“导入”，“采样方式”为“按照镜头”。
3. 点击“内置”，选择 **“内置演示·780 nm 四透镜八变量”**。
4. 截图时要保留“数据来源”“采样方式”“内置演示”文字，保存为 `fig5-03-model-a.png`。

### B 图：联合训练结果

1. 在模型页面点击“训练模型”，再点击“开始训练”。
2. 等待训练完成；结果页会显示随机森林和 XGBoost 的训练状态与测试指标。
3. 在图表下拉框中优先选择“实测值与预测值对照”；若该图信息不够完整，可改为“残差图”或“验证误差曲线”。
4. 截取图表、训练完成状态和测试指标，保存为 `fig5-03-model-b.png`。

### 截图检查点

- 只截取训练完成后的真实结果，不能截“尚未训练”。
- 图中若显示 `R²`、`MAE` 或 `RMSE`，应完整保留，便于报告说明模型可信度。

## 5. 图 5-4：优化模块的收敛曲线与候选方案

**题注：**图5-4 优化模块的收敛曲线与候选方案列表

### 平台操作

1. 从首页点击“优化”栏中的“优化变量”。
2. 在变量表中勾选 1～2 个待优化变量。优先选择与当前任务有关的“光纤横向位置”“光纤轴向位置”；若当前表中没有这两项，则选择任意两个有上下界的数值变量。
3. 选择优化目标“最大化耦合效率”。
4. 若已完成第 4 节的模型训练，可选择“训练模型辅助”，并在“训练模型”下拉框中选择刚训练完成的模型；若不使用模型，保留“当前仿真（推荐）”。
5. 点击“开始优化”，等待任务完成后平台会打开“优化结果”。
6. 在结果页图表下拉框选择“过程曲线”，使收敛曲线显示在上方；下方候选方案表应同时可见。
7. 点击候选方案表中的第一行，使“应用方案”按钮变为可用，但**不要点击“应用方案”**，以免更改当前工程参数。
8. 截取“过程曲线 + 候选方案表 + 应用方案按钮”所在的整个结果工作区，保存为 `fig5-04-optimization.png`。

### 截图检查点

- 需要看到“优化完成”或等效完成状态。
- 候选方案表至少显示一行方案及其耦合效率/状态。
- 不要截取空的“开始优化后，这里显示过程曲线”提示。

## 6. 图 5-5：SHAP 解释模块的特征重要性与物理一致性

**题注：**图5-5 SHAP 解释模块的特征重要性与物理一致性视图

本图建议由两张子图组成：`(a) 全局特征重要性`、`(b) 物理一致性图`。

### 前提

必须已完成图 5-3 的模型训练。若页面提示“请先在模型页训练”，先返回模型页完成训练；SHAP 图只能解释已选择的训练模型，不能替代正式物理仿真结论。

### A 图：全局特征重要性

1. 从首页点击“解释”栏中的“贡献排序”。
2. 在“解释模型”下拉框中选择已经训练完成的模型。
3. 在“图表”下拉框中选择“全局特征重要性排名”。
4. 点击“计算解释”，等待图表和贡献排序显示完成。
5. 截取图表及模型名称，保存为 `fig5-05-shap-a.png`。

### B 图：物理一致性

1. 保持同一个模型与同一轮解释结果。
2. 将“图表”切换为“物理一致性图”。
3. 截取该图和页面中的物理解释提示，保存为 `fig5-05-shap-b.png`。

### 截图检查点

- 不要把 SHAP 的正负贡献写成“实验因果”；它表达的是模型对样本的贡献。
- 报告中可写“用于识别模型关注的候选主导因素，并由正式仿真复核”，不要写“SHAP 已证明物理原因”。

## 7. 图 5-6：仿真模块的光路、光斑、耦合和波前结果

**题注：**图5-6 仿真模块的光路、光斑、耦合及波前分析结果

本图建议制作成 2×2 组合图：`(a) 光路图`、`(b) 光斑图`、`(c) 光纤耦合`、`(d) 波前与衍射`。

### 平台操作

1. 从首页点击“仿真”栏中的“搭建系统”，确认当前工程为 780 nm 四透镜方案；若未同步，可先在教学模块中使用“同步到仿真”。
2. 点击仿真模块的“开始计算”，等待正式计算完成。
3. 从首页的仿真栏或仿真模块二级入口依次打开：

   - “观察结果” → 光路图；
   - “测量数据” → 光斑图；
   - “分析结果” → 光纤耦合；
   - “波前与衍射” → 波前/衍射结果。

4. 每个页面都要保留图表标题、色标或坐标轴以及正式结果指标，分别截取为：

   - `fig5-06-ray.png`
   - `fig5-06-spot.png`
   - `fig5-06-coupling.png`
   - `fig5-06-wavefront.png`

5. 在 Word 中使用 2×2 无边框表格组合四张图，按 `(a)` 至 `(d)` 标注；整组下方只保留“图5-6 …”这一条题注。

### 截图检查点

- 必须先完成正式计算，否则不要截取空白或近似预览图。
- 耦合图应能看到模式耦合效率或总耦合效率；波前图应保留色标。

## 8. 图 4-1 至图 4-4：在 Word 中绘制，不需要操作平台

这四张图的作用是说明系统的开发结构和数据闭环，平台界面不会直接生成它们。可在 Word 中用“插入 → 形状 → 圆角矩形/箭头”制作，所有框使用白底、深蓝细边、黑色文字，箭头由左向右或自上而下。

### 图4-1 平台总体架构与任务数据流

画五个横向模块，并用箭头相连：

`交互展示层（教学/仿真界面） → 工程与任务管理层（工程快照、任务状态、结果版本） → 物理计算层（Gaussian/ABCD、光线追迹、复场传播、模式重叠） → 智能分析层（数据集、代理模型、优化、SHAP） → 结果层（光路、光斑、耦合、波前、报告）`

### 图4-2 工程快照、任务状态与结果追溯关系

按以下链条画六个框：

`工程参数快照 → 可行性检查 → 提交计算任务 → 中间诊断（有效光线、网格、能量） → 最终指标（模式/总耦合效率） → 图表、模型和优化结果`

在“工程参数快照”向“最终指标”“图表、模型和优化结果”各补一条虚线，标注“版本号/任务 ID 可追溯”。

### 图4-3 正式仿真计算链与结果诊断

按以下链条画八个框：

`输入工程参数 → Gaussian/ABCD 快速估计 → 顺序光线追迹 → 公共出射面复场重建 → 角谱/Fresnel 传播 → 光纤目标模场 → 归一化复场重叠 → 光路/光斑/耦合/波前诊断`

在“顺序光线追迹”“公共出射面复场重建”“角谱/Fresnel 传播”下方各加小注释：有效光线比例、网格收敛/边缘功率、能量闭合。

### 图4-4 物理仿真、代理模型、优化和 SHAP 的闭环

按环形或闭环箭头画：

`正式物理仿真 → 数据集 → 代理模型训练 → 候选方案优化 → 正式仿真复核 → SHAP/物理解释 → 参数调整 → 正式物理仿真`

在“候选方案优化 → 正式仿真复核”箭头旁标“候选筛选不等于最终结论”；在“SHAP/物理解释”旁标“模型贡献需由正式仿真复核”。

## 9. 插入报告的统一规则

1. 在研究报告中，找到对应的“（待补图）”或“（待截图）”题注行。
2. 将光标放在题注行**上方**，使用“插入 → 图片 → 此设备”插入 PNG。
3. 设置图片为“嵌入型”、水平居中；不要使用环绕方式遮挡正文。
4. 保留现有题注，删除题注中的“（待补图）”或“（待截图）”。不要再使用 Word 自动题注，否则会出现重复编号。
5. 图注位于图下方并居中：中文宋体五号，英文和数字 Times New Roman 五号。
6. 图片全部插入后，目录页码会变化；请重新核对目录，或将插图后的文档交回统一更新目录。

## 10. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| “内置演示·780 nm 四透镜八变量”没有出现 | 关闭程序后运行一次 `python .\tools\run_demo.py`，再进入模型页点击“内置”；之后仍可继续用 `python .\app.py` 启动。 |
| 训练结果为空或 SHAP 提示先训练 | 回到“模型 → 准备数据集”，点击“内置”采用数据集，再点击“训练模型 → 开始训练”。 |
| 优化按钮不可用 | 先在“优化变量”表中勾选至少一个变量；若使用“训练模型辅助”，还要选择训练完成的模型。 |
| 仿真页没有结果 | 回到仿真模块并点击“开始计算”，等待正式计算完成后再打开光路、光斑、耦合或波前页面。 |
| 图太小、字看不清 | 用最大化窗口重新截图，保留原始 PNG；不要把截图二次压缩后再插入 Word。 |
